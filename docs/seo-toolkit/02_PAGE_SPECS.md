# Reusable page pattern

Every content page should have:

1. breadcrumb
2. eyebrow/freshness status
3. H1
4. 1–2 sentence answer-first intro
5. primary table/tool/content immediately
6. compact source/status explanation
7. deeper guide sections
8. FAQ only if questions add value
9. `Next useful step` internal links
10. footer
