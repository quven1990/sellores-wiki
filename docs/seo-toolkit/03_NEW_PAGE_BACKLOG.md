# 03 — New Page Backlog

Do not build these as thin SEO pages. Build only when there is enough reliable data or a genuinely useful workflow.

> **Mandatory evidence gate:** Before building any route in this file, read `07_CONTENT_EVIDENCE_POLICY.md`. A backlog item is an opportunity, not an instruction to fabricate a page. If reliable source material is insufficient, keep it unbuilt.

# Content expansion rule

A new page must pass all of these before indexable launch:

- answers a distinct player intent
- contains unique useful information or utility
- no placeholder/skeleton main section
- 3+ internal links in and 3+ out where logically possible
- unique metadata
- source/status system used consistently
- useful on mobile

If it fails, keep it in backlog instead of publishing it.
